# decisions.md — Onboarding decisions (durable, committed)

Onboarding steps record their **decisions** here so **future sessions read them and never
re-ask**. This is the repo's memory of what the user chose (per CLAUDE.md Golden Rule #8:
the repo is the source of truth, not agent memory). Keep entries short; each starts with the
decision and the date it was recorded.

> Contains **no third-party personal data**. When a decision involves email or contacts, record
> the choice and method only — never store email contents or a third party's real name here.
