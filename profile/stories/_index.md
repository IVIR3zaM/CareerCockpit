# STAR Story Bank

Behavioral evidence — the raw anecdotes that power interviews **and** give CV bullets their
credibility. One story per file (see `_TEMPLATE.md`).

Keep stories **factual and specific**. Each links to the roles/projects it came from and
the interview themes it can answer. Use role-based aliases for other people, never real
names (see the privacy rule in CLAUDE.md).
