# Applications — Master Index

The log of every **live** job application. The agent appends/updates a row here whenever an
application is created or its status changes. Full details live in each application's
folder.

Status values (live): `interested` · `applied` · `screening` · `interviewing` · `offer` ·
`accepted`

> 🗄️ **Closed applications are not here — they are in
> [`_archive/_index.md`](_archive/_index.md).** When an application reaches a terminal status
> (`rejected` · `withdrawn` · `ghosted` · `not applied — skipped`), its row and folder move to
> the archive verbatim (`CLAUDE.md` §2.5, Golden Rule #14). **This file is therefore only half
> the history** — every "have I applied there before?" check, the repeat-applicant gate (#12),
> and the failure-class recurrence check (#13) read **both** indexes.
