# Interviews

Prep material, organized so it compounds across every application.

- **[`question-generator.md`](question-generator.md)** — **start here for any prep.** Generates
  the full candidate question list for the user's discipline + level + round type. The saved
  banks are a seed; the generator is the source of the actual list.
- **`hiring-manager/`** — behavioral / leadership rounds:
  - [`question-bank.md`](hiring-manager/question-bank.md) — seed question bank (leadership rows
    gated to people-managers).
  - [`answers.md`](hiring-manager/answers.md) — STAR answers, keyed to the bank, cited to
    `profile/stories/`.
  - [`prep-checklist.md`](hiring-manager/prep-checklist.md) — the coverage gate every prep plan
    must walk.
- **`technical/`** — discipline-technical rounds (system design, coding, design critique,
  product/analytics case). See [`technical/README.md`](technical/README.md).
- **`company-research/`** — per-company research notes, linked from each `application.md`. Use
  the `_TEMPLATE.md` there.

**Golden rules that apply here:** never fabricate an answer; every claim traces to `profile/`;
alias all third parties by role (never a real name); keep employer specifics generic. See the
user's `CLAUDE.md`.
